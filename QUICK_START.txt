🔧 COMMON ISSUES & FIXES
════════════════════════════════════════════════════════════════════════════

Port conflicts:
  $ lsof -i :8080  # Check what's using port 8080
  $ kill -9 <PID>  # Kill it

Database won't initialize:
  $ docker-compose logs postgres
  $ docker-compose exec postgres psql -U iicpc_user -d iicpc_metrics
  $ \dt  # List tables (should see metrics, submissions, etc.)

Services won't start:
  $ docker-compose down -v  # Remove everything
  $ docker-compose up       # Start fresh

Memory issues:
  $ docker stats  # Watch memory usage
  Check bot goroutine count (should be ~5000)
  Reduce NUM_BOTS env variable if needed

Leaderboard not updating:
  $ docker-compose logs ws-server
  Check browser console (F12) for JavaScript errors
  Verify WebSocket connection to http://localhost:8083
