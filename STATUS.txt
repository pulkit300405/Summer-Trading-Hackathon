────────────────────────────────────────────────────────────────────────────
💡 KEY INSIGHTS
────────────────────────────────────────────────────────────────────────────

WHY GO:
  - Goroutines: 5K concurrent bots with minimal memory footprint
  - Performance: Compiled binary, low latency
  - Simplicity: No complex frameworks, easy to debug

WHY POSTGRESQL + TIMESCALEDB:
  - Time-series optimized: Built-in percentile queries
  - No extra infrastructure: Single database, no Kafka/Redis overhead
  - Simple: SQL for everything, familiar to most engineers

WHY DOCKER COMPOSE (for development):
  - One-liner: docker-compose up
  - Portable: Works on laptop, cloud VMs, GitHub Actions
  - All services together: No need to run each separately

WHY REACT FRONTEND:
  - Real-time: WebSocket integration straightforward
  - Charting: Recharts library for latency/throughput visualization
  - Familiar: Most engineers know React
